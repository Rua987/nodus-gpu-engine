Why — the hidden tax

Every agentic system pays to plan before it acts.

Before a frontier model can do anything, it burns tokens just to decide what to do — and for simple tasks, planning can cost more than the work itself. Nodus replaces that phase with a 324M-parameter transformer fine-tuned on a single job: task → ordered list of tool names. No arguments, no replanning.

The model can’t write great code — but “which tools, in what order?” is a much simpler question than “write the code.” The big model keeps the only job it’s actually good at: executing.

Pipeline — plan, execute, deliver, observe

One run, four phases. The order is the product.

01

Plan

The 324M planner reads the task and emits a fixed 8-tool vocabulary — just names, in order.

→ ["read_file", "write_file", "bash", "gcs_upload"]
02

Execute

The harness fills the arguments, runs each tool, and verifies the result against guardrails.

→ Gemini via Vertex AI (Agent Builder)
03

Deliver

The media workflow uploads the finished artifact to Google Cloud Storage.

→ gs://nodus-media-demo/production/…
04

Observe

Every event becomes a tagged Grafana annotation — the dashboard is the agent’s scope.

→ mcp-grafana · create_annotation

Google Cloud — in code, mock-first

The executor and the delivery both run on Google Cloud.

Executor · Agent Builder

Gemini via Vertex AI

The ReAct loop runs on vertex:gemini-2.5-flash — the official google-genai SDK built with vertexai=True, the Agent Builder / Gemini Enterprise runtime. Native function calling; ADC auth instead of an API key. The same SDK also supports the Gemini API (gemini: prefix) for other regions.

  • Import & call in code — no key in the repo
  • Guards — fails loudly only if you request a vertex/gemini model
Delivery · Cloud Storage

gcs_upload

The media workflow finishes by uploading the artifact to gcs://nodus-media-demo/…. Mock-first: a deterministic gs:// URI with zero credentials, or a real upload via the official google-cloud-storage SDK when ADC is present.

  • Harness capability — the planner’s 8-tool vocabulary stays fixed
  • Honest mode — a [mock] marker on every URI
Vertex AI — Google Cloud Agent Builder 
# runs the whole loop on Gemini via Vertex AI (ADC auth)

Observability — partner service

An agent session you can replay, correlate, and audit.

Nodus activates Grafana Cloud through the official mcp-grafana server. Every normalized event — task, plan, each tool call, each result — becomes a tagged create_annotation call, landing in a dashboard as live annotations.

Mock mode collects the same events in memory + JSONL with zero setup — perfect for CI and the video. Live mode needs only a free Grafana account and a service-account token. MCP failure is never fatal to a run.

Run it yourself — 30 seconds, zero dependencies

No checkpoint. No API key. No container.

1 · install
pip install -r requirements-ci.txt
2 · plan a task (orchestrator)
# with the checkpoint in checkpoints/, the 324M model answers:
$ echo "read src/main.py, then search for request_id, then edit it" \
    | python nodus_plan_local.py --plan-once
{"ok": true, "names": ["read_file", "grep", "edit_file"]}
3 · the media demo, end to end
# uses the real 324M planner when the checkpoint is present,
# otherwise a deterministic gold plan — either way, fully offline
$ python demo_agentic_cinema.py --task-key media
4 · mock timeline (no LLM API)
# same pipeline as judges, fully offline — JSONL instead of Grafana MCP
$ NODUS_GRAFANA=jsonl:run.jsonl python demo_agentic_cinema.py --task-key media
5 · Agentic Cinema judges (live Vertex + GCS + Grafana)
# see AGENTIC_CINEMA.md — Google Cloud AI + Grafana MCP only
$ python demo_agentic_cinema.py --live --model vertex:gemini-2.5-flash --task-key media
